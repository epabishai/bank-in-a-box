# Security policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues or pull requests.
Use [Report a vulnerability](https://github.com/epabishai/bank-in-a-box/security/advisories/new)
to submit a private report to the maintainers. Include the affected version,
reproduction steps, impact, and any suggested mitigation. Do not include
credentials or sensitive customer data.

Maintainers will review the report privately, coordinate a fix and disclosure
with the reporter, and provide updates through the advisory.
